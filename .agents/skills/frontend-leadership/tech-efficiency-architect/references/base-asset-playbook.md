# 基础资产建设与业务推行

## 核心定位

模板项目、组件库、工具库和小程序模板，不是工具清单，而是复用底座。

## 适用资产

- 模版项目优化打磨
- APP 组件库
- Web 组件库
- 工具库
- 小程序项目前置搭建
- 景云销组件 React 重构
- 景云销项目 React 重构

## 演进路径

1. 0 -> 1：先把能用的东西做出来
2. 1 -> 2：打磨稳定性、文档和接入方式
3. 2 -> N：推动业务项目真正使用

## 推广动作

- 先选一个试点项目
- 再补接入清单和迁移说明
- 再统计覆盖率和复用率
- 再做版本化维护

## 评估指标

- 新项目启动时间
- 接入项目数
- 复用率
- 维护成本
- 文档完备度

## 结论

资产建设的判断标准不是“做没做”，而是“有没有真正进入业务交付”。

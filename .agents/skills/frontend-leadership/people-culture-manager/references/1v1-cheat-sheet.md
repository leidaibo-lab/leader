# 1v1 控场速查表 (Cheat Sheet)

> **使用说明**: 打印出来贴在笔记本一角，或者放在屏幕旁边。聊的时候瞄一眼，保证不超时。

## ⏱️ 45分钟倒计时 (The Rhythm)

| 时间段 | 关键动作 | 话术检查点 |
| :--- | :--- | :--- |
| **00-03 分** | **定调** | "咱们今天只有45分钟，主要聊你的成长。" |
| **03-18 分** | **听他说** | (只听不评，记下痛点) |
| **18-28 分** | **你反馈** | "我觉得你在XX方面不错，但明年希望在XX上有变化。" |
| **28-40 分** | **定规划** | "明年有个XX方向，你有兴趣吗？" (或直接派任务) |
| **40-45 分** | **结案** | "好，那咱们就定这两件事：我做A，你做B。" |

---

## 🚦 针对不同人的策略 (The Gearbox)

*   **😐 普通/话痨员工**:
    *   **策略**: **少听多讲**。听10分钟 -> 教育20分钟 -> 定任务。
    *   **心态**: 只要明确红线，任务下达，就是胜利。

*   **🌟 核心骨干**:
    *   **策略**: **多听多画饼**。听25分钟 -> 共同规划20分钟。
    *   **心态**: 让他觉得被重视，被当作"合伙人"。

*   **⚠️ 问题员工**:
    *   **策略**: **只讲不听**。听解释10分钟 -> 严肃反馈(PIP)20分钟。
    *   **心态**: 不要给幻想，直接给压力。

---

## ✂️ 救命打断话术 (Interruption Phrases)

> *当你感到烦躁、时间不够、或者对方开始跑题时，直接读这几句：*

1.  **打断吐槽 (抱怨环境)**
    *   "这个情况我了解了。咱们换个角度，**如果明年还是这个环境，你打算怎么适应？**"

2.  **打断炫耀/对比 (在那比来比去)**
    *   "这点确实不错。除此之外，**有没有哪个项目是你觉得做完之后，还有很大遗憾的？**"

3.  **打断跑题 (聊嗨了)**
    *   "咱们时间过半了，我特别想听听你对**明年个人成长**的规划，咱们聊聊这个？"

4.  **强制结束 (超时了)**
    *   "今天聊得很开心，剩下的细节咱们**下次周会后单独再约15分钟**，今天先到这。"

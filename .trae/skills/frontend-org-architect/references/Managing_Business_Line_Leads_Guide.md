# 业务线负责人管理指南 (Managing Business Line Leads Guide)

本文档旨在帮助 Frontend Lead 有效管理下属的业务线负责人（Business Line Leads, 简称 BLL），实现从“直接管理”到“间接管理（Managing Managers）”的跨越。

## 一、核心原则：管结果、理过程、定边界

对 BLL 的管理不再是盯着具体的代码实现，而是关注他们的**判断力**、**执行力**和**团队健康度**。

### 1. 角色定位：他是业务线的“小 CEO”
*   **不仅仅是传声筒**: BLL 不能只做“二传手”，必须对业务的技术结果（质量、进度、体验）负全责。
*   **Owner 意识**: 当业务出现问题时，BLL 是第一责任人，而不是底下的开发人员。
*   **技术决策者**: 在业务域内的技术选型、架构设计，由 BLL 提案，Lead 审核。

### 2. 授权边界 (Delegation Boundary)
| 事项类型 | 权限级别 | 示例 |
| :--- | :--- | :--- |
| **日常执行** | **完全授权** | 任务分配、Code Review、每日站会、Bug 修复 |
| **战术决策** | **报备后执行** | 技术方案设计、两周内的排期调整、新人试用期评估 |
| **战略决策** | **必须审批** | 引入新框架/库、跨月延期、招聘/解雇建议、跨组借调 |
| **危机处理** | **立即上报** | 线上 P0 故障、核心人员离职风险、业务方严重投诉 |

## 二、管理抓手：如何监控与考核

利用 [Business_Line_Lead_Execution_Standards.md](Business_Line_Lead_Execution_Standards.md) 中的标准作为考核基准。

### 1. 过程指标 (Leading Indicators) - 看执行
*   **SOP 执行率**: 是否按时开了站会？Code Review 是否达标（>2人审）？技术方案是否评审？
    *   *检查方式*: 抽查 Git Merge Request 记录、参加一次他们的站会/周会。
*   **风险上报及时性**: 是否总是在最后一刻才说延期？
    *   *红线*: 所有的延期必须至少提前 3 天预警，否则视为 BLL 失职。

### 2. 结果指标 (Lagging Indicators) - 看产出
*   **质量数据**: 线上故障数、Sentry 报错率、回滚次数。
*   **交付效能**: 需求按时交付率、研发周期（Lead Time）。
*   **团队稳定性**: 组员流失率、组员满意度（通过 Skip-level 1v1 获取）。

### 3. 周期性对齐 (Rhythm)
*   **周会 (Weekly Sync)**: BLL 汇报本周产出与下周计划，重点讨论**跨组依赖**与**资源冲突**。
*   **月度复盘 (Monthly Review)**: 拿着数据说话，复盘上个月的质量与效能，制定改进计划。

## 三、辅导与赋能 (Coaching & Enabling)

BLL 通常是技术骨干转型，最容易犯“事必躬亲”或“不敢管人”的错误。

### 1. 常见问题辅导
*   **问题 A: 自己写代码太忙，没空管团队**
    *   *对策*: 强制要求 BLL 减少 Coding 时间（如降至 50%），设立“非 Coding 贡献”考核项。
*   **问题 B: 做老好人，不敢给组员打低绩效**
    *   *对策*: 教导“慈不掌兵”，明确绩效分布要求，Lead 参与绩效校准会 (Calibration)。
*   **问题 C: 业务方强势，不仅接需求还背锅**
    *   *对策*: Lead 出面撑腰，教 BLL 如何用技术视角回绝不合理需求（Say No 的艺术）。

### 2. 梯队建设
*   **Backup 机制**: 要求 BLL 培养自己的 Backup（副手），否则不能晋升。
*   **轮岗机制**: 鼓励 BLL 在不同业务线轮岗，防止山头主义。

---

## 四、优胜劣汰 (Up or Out)

对于不胜任的 BLL，要有清晰的处理路径：
1.  **观察期 (1个月)**: 明确指出 gap，制定 PIP (Performance Improvement Plan)，改为周度高频辅导。
2.  **转岗/降级**: 如果技术强但管理弱，转为纯技术专家 (IC 路线)，保留体面。
3.  **劝退**: 价值观问题（如隐瞒故障、拉帮结派）零容忍。
